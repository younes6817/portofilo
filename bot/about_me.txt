## درباره یونس

یونس یک توسعه‌دهنده وب Python/Django است که تمرکز اصلی او روی Backend Development و ساخت Web Applicationهای واقعی و کاربردی است.

او بیشتر با Python و Django کار می‌کند و در زمینه ساخت Backend System، REST API، Authentication، Authorization، Database-driven Application، Admin Panel، Dashboard، Marketplace، Management System و سیستم‌های تجاری فعالیت دارد.

در کنار Backend، در پروژه‌های وب با HTML، Tailwind CSS و JavaScript نیز کار می‌کند و در صورت نیاز می‌تواند یک Web Application کامل را از Backend تا بخش Frontend پیاده‌سازی کند.

یونس بیشتر به ساخت محصولاتی علاقه دارد که برای یک نیاز واقعی طراحی شده‌اند، نه صرفاً پروژه‌های نمایشی یا تمرینی.
